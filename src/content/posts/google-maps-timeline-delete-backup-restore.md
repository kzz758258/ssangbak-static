구글 타임라인은 **특정 방문, 하루, 지정 기간, 전체 기록** 중 원하는 범위만 삭제할 수 있습니다. 휴대전화를 바꿀 예정이라면 삭제보다 먼저 Google 지도 앱의 내 타임라인에서 **클라우드 모양 백업 아이콘이 켜져 있는지** 확인하세요. 백업이 없으면 기기 초기화 후 과거 기록을 복원하지 못할 수 있습니다.

[Google 타임라인 백업·삭제 공식 도움말 보기](https://support.google.com/maps/answer/6258979?co=GENIE.Platform%3DAndroid&hl=ko)

## 삭제·백업 메뉴 차이

| 원하는 작업 | 메뉴 | 결과 |
| --- | --- | --- |
| 특정 방문만 지우기 | 날짜 선택 → 방문 옆 더보기 → 삭제 | 선택한 방문 기록만 삭제 |
| 하루 기록 지우기 | 날짜 선택 → 더보기 → 1일 위치 기록 삭제 | 해당 날짜 전체 삭제 |
| 기간 지정 삭제 | 위치 및 개인정보 보호 설정 → 특정 기간 삭제 | 시작일~종료일 삭제 |
| 전체 타임라인 삭제 | 위치 및 개인정보 보호 설정 → 모든 데이터 삭제 | 해당 기기의 타임라인 전체 삭제 |
| 새 기기로 옮기기 | 내 타임라인 → 클라우드 → 백업·가져오기 | 암호화된 백업을 새 기기로 복원 |

삭제한 타임라인은 복구가 어려울 수 있습니다. 여행 경로나 업무 이동 증빙처럼 나중에 필요할 기록이 있다면 날짜와 장소를 먼저 확인하고 필요한 내용은 별도로 보관하세요.

## 구글 타임라인 삭제 방법

### 특정 방문 또는 하루만 삭제

1. Google 지도 앱에서 프로필 사진 → 내 타임라인을 엽니다.
2. 상단의 ‘오늘’을 눌러 삭제할 날짜를 선택합니다.
3. 방문 한 곳만 지우려면 해당 방문 옆 더보기 → 삭제를 누릅니다.
4. 하루 전체를 지우려면 화면 위 더보기 → 1일 위치 기록 삭제를 선택합니다.
5. 날짜와 범위를 다시 확인하고 삭제를 확정합니다.

### 특정 기간 또는 전체 삭제

1. 내 타임라인에서 더보기 → 위치 및 개인 정보 보호 설정을 엽니다.
2. ‘특정 기간의 타임라인 데이터 삭제’ 또는 ‘모든 타임라인 데이터 삭제’를 선택합니다.
3. 기간 삭제는 시작일과 종료일을 지정합니다.
4. 경고 문구와 대상 계정·기기를 확인한 뒤 진행합니다.

한 기기의 데이터를 지웠다고 다른 기기의 타임라인까지 항상 같이 지워지는 것은 아닙니다. 여러 기기를 사용했다면 각 기기의 기록과 백업 상태를 따로 확인하세요.

## 자동 삭제 기간 설정

타임라인은 3개월, 18개월, 36개월이 지난 데이터를 자동으로 삭제하도록 설정할 수 있습니다.

1. 내 타임라인 → 더보기 → 위치 및 개인 정보 보호 설정으로 이동합니다.
2. 타임라인 자동 삭제를 누릅니다.
3. 보관 기간을 선택하거나 자동 삭제 안 함을 선택합니다.
4. 적용될 데이터 범위를 확인하고 저장합니다.

백업을 켜려는데 메뉴가 활성화되지 않으면 자동 삭제가 켜져 있는지 먼저 확인하세요. Google 공식 도움말은 백업을 사용하려면 자동 삭제를 꺼야 할 수 있다고 안내합니다.

## 휴대폰 변경 전 백업 방법

Google 지도 타임라인 백업은 데이터의 암호화된 사본을 Google 서버에 저장합니다. Android와 iPhone 모두 다음 흐름으로 확인합니다.

1. 이전 휴대전화에서 Google 지도 앱을 엽니다.
2. 프로필 사진 → 내 타임라인을 선택합니다.
3. 오른쪽 위 클라우드 아이콘을 누릅니다.
4. 자동 삭제가 켜져 있다면 안내에 따라 끕니다.
5. 백업을 사용 설정하고 계정 비밀번호 확인을 완료합니다.
6. 변경 내용이 백업에 반영될 때까지 시간이 걸릴 수 있으므로 즉시 초기화하지 않습니다.

## 새 휴대폰에서 타임라인 복원하기

1. 새 기기에 Google 지도 앱을 설치하고 같은 Google 계정으로 로그인합니다.
2. 프로필 사진 → 내 타임라인 → 클라우드 아이콘을 엽니다.
3. ‘내 백업’에서 이전 기기를 선택합니다.
4. 더보기 → 가져오기를 누릅니다.
5. 비밀번호를 입력하고 가져오기를 완료합니다.
6. 날짜별 기록이 보이는지 확인한 뒤 이전 기기를 초기화합니다.

백업을 켠 직후에는 최신 이동이 아직 반영되지 않을 수 있습니다. 중요한 기록이 있다면 여러 날짜를 직접 열어 확인하세요.

## 백업 삭제와 타임라인 삭제는 다릅니다

클라우드에서 기기 백업을 ‘사용 중지 및 삭제’해도 현재 휴대전화에 저장된 타임라인이 함께 삭제되는 것은 아닙니다. 반대로 기기에서 타임라인 전체를 삭제하면 백업 상태에 따라 다른 기기에서 보이는 데이터와 차이가 생길 수 있습니다.

또 타임라인을 삭제해도 웹 및 앱 활동, Google 검색 서비스 기록, 사진 위치정보에 별도의 위치 데이터가 남을 수 있습니다. 위치정보 전체를 정리하려면 Google 계정 활동 설정과 카메라 위치 태그도 확인하세요.

## 자주 묻는 질문

### Q. 삭제한 타임라인을 복구할 수 있나요?

**A.** 삭제는 되돌리기 어려우므로 백업이 있더라도 복구를 전제로 지우면 안 됩니다. 삭제 전 필요한 날짜를 따로 확인하세요.

### Q. 백업을 삭제하면 휴대폰 기록도 지워지나요?

**A.** Google 안내에 따르면 백업 사용 중지·삭제만으로 기기에 저장된 타임라인 데이터가 삭제되지는 않습니다.

### Q. 새 휴대폰에서 과거 기록이 안 보이는 이유는 무엇인가요?

**A.** 다른 계정으로 로그인했거나 이전 기기에서 백업하지 않았거나, 백업 반영 전 초기화했을 가능성을 확인하세요.

### Q. 자동 삭제와 백업을 동시에 쓸 수 있나요?

**A.** 앱 안내에 따라 백업을 켜기 전에 자동 삭제를 꺼야 할 수 있습니다. 최신 Google 지도 앱의 백업 화면을 기준으로 설정하세요.

## 초기화는 복원 확인 뒤에 하세요

휴대폰을 바꿀 때는 이전 기기에서 백업을 켜는 것만으로 끝내지 말고 새 기기에서 실제 날짜별 기록을 확인해야 합니다. 삭제할 때도 방문·하루·기간·전체 범위를 다시 확인하면 필요한 이동기록까지 한꺼번에 잃는 일을 줄일 수 있습니다.
