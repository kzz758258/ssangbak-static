# SsangBak 콘텐츠 성장 로드맵

작성 기준일: 2026-08-09

## 1. 현재 진단

- 기존 글은 모두 런타임 분류되고 있었지만 `지원금&정부정책`, `생활정보`, `엔터&스포츠` 3개 축이 너무 넓었다.
- 글 544개는 운영을 멈출 만큼 많은 수가 아니다. 다만 무작위로 폭을 넓히기보다 기존 주제의 검색 의도를 완성할 수 있을 만큼 충분한 기반이다.
- 공연·예매 글은 종료 뒤 가치가 급격히 낮아지므로 과거 글 재작성과 시리즈 편입 대상에서 제외한다. 앞으로도 판매 중인 일정만 검증해 빠르게 발행한다.
- 증명서·세금·지원제도처럼 반복 수요가 있는 글은 최신 기준 유지, 내부 연결, 공식 행동 경로가 장기 성과에 더 중요하다.

## 3. 우선 완성할 묶음

### A. 민원·증명서 발급

허브 질문은 `어떤 서류를 어디에 제출해야 하는가`다. 주민등록표 초본, 가족관계증명서, 인감증명서, 소득금액증명, 납세증명, 건강보험·고용보험 증명, 건축물·토지·자동차 원부 글을 하나의 시리즈로 연결한다.

각 글은 다음 차이가 반드시 있어야 한다.

1. 제출 목적별 올바른 서류와 포함 항목
2. 온라인·방문 발급 가능 여부, 수수료, 본인인증 방식
3. PDF 저장과 전자문서지갑 사용 조건
4. 전년도 자료가 안 보이는 경우 등 해당 서류 고유 오류
5. 실제 공식 발급 페이지로 가는 명확한 버튼 1회

### B. 학자금대출

2학기 신청, 생활비 대출 한도, 농촌 학자금, 지자체 이자지원, 중도상환을 의사결정 순서로 연결한다. 같은 신청 방법을 반복하지 않고 각 글이 `대상 판정`, `금액·이자`, `신청`, `상환` 중 하나를 깊게 맡는다.

근로장려금은 이미 별도 시리즈가 있어 중복 시리즈를 만들지 않고 유지한다.

## 4. 지역정보 운영 원칙

지역정보는 SsangBak 안의 독립 메인 카테고리로 먼저 검증한다. 새 도메인이나 서브도메인은 최소 30~50개의 검증된 지역 데이터와 반복 방문 도구가 확보된 뒤 판단한다.

발행 조건:

- 지자체·공공기관의 직접 출처가 있다.
- 지역별 요금, 신청처, 배출일, 운영시간, 할인 조건처럼 고유값이 있다.
- 독자가 주소나 조건을 입력해 다음 행동을 결정할 수 있다.
- 지역명만 교체한 문서가 아니다.
- 마지막 확인일과 변경 가능 항목을 표시한다.

우선순위:

1. 대형폐기물 품목별 수수료·신고 앱·수거일
2. 공영주차장 요금·무료시간·감면·정기권
3. 자동차 검사·리콜·과태료와 지역 검사소
4. 소상공인 인허가·신고·필요 서류
5. 공동주택 관리비·이사 정산·장기수선충당금

장례·의료·법률·투자 예측처럼 오류 비용이 큰 주제는 초기 확장 대상에서 제외한다.

## 5. 정책·지원금 조기 감지

현재 `topic-radar`는 Google News RSS, Naver News API, OpenAI 웹 검증, 기존 글 중복 검사를 사용한다. 여기에 정부·기관 도메인 중심 질의를 추가했다.

권장 데이터 순서:

1. K-Startup 창업지원포털 공공데이터 API
2. 기업마당과 중소벤처기업부 사업공고
3. 고용노동부·복지부·국토부·지자체 공고
4. 정부24·보조금24 변경 공지
5. 뉴스와 검색어 데이터는 발견·우선순위 판단에만 사용

API가 찾아낸 사실을 바로 자동 발행하지 않는다. 신규·변경·마감임박을 감지한 뒤 공식 원문에서 대상, 금액, 기간, 신청 경로를 검증하고, 기존 글과 겹치지 않을 때 초안을 만든다. 긴급 공고는 같은 날, 계절형은 최소 3영업일 전에 발행하는 것을 목표로 한다.

## 6. 발행량과 품질 기준

- 새 글 발행은 계속하되 주간 물량의 절반 이상을 우선 묶음의 빈 검색 의도에 배정한다.
- 오래된 공연처럼 종료된 글은 일괄 수정하지 않는다.
- 장기 글은 공식 기준 변경, 검색 노출, 내부 링크 필요성이 있을 때 갱신한다.
- 글 수 목표보다 `검증 가능한 고유 정보`, `독자가 얻는 결정`, `다음 공식 행동`을 통과 기준으로 삼는다.
- CTA는 공식 신청·조회·발급·구매 등 실제 행동이 있을 때만 1~2회 사용한다. 광고 클릭을 유도하거나 막연한 긴급성을 만들지 않는다.

## 7. 도메인 확장 판단

지금은 새 도메인보다 SsangBak의 카테고리 신호와 데이터 파이프라인을 강화한다. 별도 도메인은 한 주제만으로 검색·재방문·제휴 수익을 독립적으로 만들 수 있고, 중복 콘텐츠 없이 운영할 인력과 데이터가 있을 때만 검토한다. 서브도메인도 검색 신뢰를 자동으로 물려받는 지름길로 보지 않는다.
