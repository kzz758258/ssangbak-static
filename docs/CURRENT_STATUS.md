# SsangBak 현재 상태

최종 확인: 2026-09-19

이 문서는 새 작업을 시작할 때 가장 먼저 확인하는 운영 현황이다. 코드나 외부 서비스 상태가 달라지면 확인한 날짜와 내용을 함께 갱신한다.

| 항목 | 현재 상태 |

## 현재 구현된 기능

- 기존 WordPress 글의 URL과 카테고리 URL을 정적 경로로 유지
- 홈·카테고리·글 상세 페이지 제공
- 모바일 썸네일 오버레이 제목과 카테고리 표시
- 글별 지정 `relatedPosts`와 미지정 글의 최신 관련 글 추천
- 사용자 행동 순서에 맞춘 일부 시리즈 구성
- 공식 출처 목록, FAQ, CTA, 반응형 표를 지원하는 콘텐츠 구조
- 품질 검사 `npm run content:check`
- 품질 검사와 Astro 검사·빌드를 묶은 `npm run build`
- 압축 로그 빌드 `npm run build:quiet`
- 네이버 리서치와 topic radar 스크립트
- GitHub Actions 일일 topic radar 보고서 갱신
- `/sitemap.xml`과 `/sitemap_index.xml`을 `/sitemap-index.xml`로 301 리디렉션

## 현재 운영 방식

1. 최신 정보와 공식 출처를 조사한다.
2. 기존 글과 검색 의도 중복을 확인한다.
3. 원고·썸네일·내부 링크를 제작한다.
4. 품질 검사와 빌드를 실행한다.
5. 승인된 변경을 `main`에 푸시한다.
6. Cloudflare Pages 배포 후 실제 URL을 확인한다.

주제 탐색은 자동화되어 있지만 원고 작성과 배포는 사람 검수를 포함한 반자동 방식이다.

## 현재 콘텐츠 방향

- 증명서 발급, 지원제도, 세금·생활금융처럼 반복 수요가 있는 주제를 장기 자산으로 강화한다.
- 새 글을 중단하지 않되 주간 발행의 상당 부분을 기존 주제 묶음의 빈 검색 의도에 배정한다.
- 공연 글은 예매가 진행 중이거나 확정 공지가 있는 경우에만 빠르게 발행한다.
- 시리즈는 지역이나 카테고리가 같다는 이유가 아니라 `조건 → 신청 → 조회 → 문제 해결`처럼 다음 행동이 연결될 때 구성한다.
- 행동형 키워드는 적극 활용하되 공식 페이지 사칭과 광고 클릭 유도는 하지 않는다.

## 확인된 미완료·위험 항목

### 우선 확인

- Search Console API 기반 색인·검색어·CTR·순위 자동 수집이 없다.
- Google Ads 구매 전환 태그와 확정 수익 자동 연동은 없다. GA4의 제휴 이동·CTA 클릭 측정만 구현했다.
- 미래 `pubDate`가 실제 예약 공개를 보장하지 않는다. 예약 발행으로 간주하면 안 된다.
- 자동 발행은 아직 없다. GitHub Actions는 주제 보고서만 생성한다.

### 콘텐츠 운영

- 592개 전체 글이 최신 콘텐츠 표준을 충족하는 것은 아니다.
- 과거 글에는 시의성이 끝난 공연, 빈약한 출처, 중복 가능성이 남아 있을 수 있다.
- 전체 일괄 수정보다 Search Console 성과와 위험도를 기준으로 선별 보강해야 한다.

### 광고·수익화

- 순수 애드센스 차익거래 캠페인은 계획하지 않는다.
- 쇼핑커넥트형 상품 비교를 1차 후보, 여행·숙박 예약 제휴를 2차 후보로 정했다.
- `docs/PAID_ADS_PILOT_PLAN.md`에 랜딩 가치, 전환 추적, 손익·중단 기준을 설계했다.
- 기존 폴드8 사전예약 글은 기간이 끝나 현재 광고 랜딩으로 사용하지 않는다.
- 새 도메인·서브도메인은 아직 확정하지 않았다.

## 로컬 작업공간 주의사항

2026-09-19 확인 당시 추적되지 않은 과거 리서치 보고서, 썸네일 시안, 임시 파일이 존재한다. 이 파일들은 사용자 작업일 수 있으므로 별도 확인 없이 삭제하거나 일괄 커밋하지 않는다.
