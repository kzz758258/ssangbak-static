# SsangBak 프로젝트 명세

최종 확인: 2026-09-19

## 1. 프로젝트 목적

SsangBak은 정부지원, 민원·발급, 세금·금융, 지역정보, 생활정보, 엔터·스포츠 분야에서 독자가 대상 여부와 다음 행동을 빠르게 판단하도록 돕는 정보 사이트다.

목표는 글 수 자체가 아니라 다음 세 가지다.

1. 공식 자료를 독자의 실제 질문에 맞게 해석한다.
2. 신청·발급·조회·예약·구매 과정의 실패 지점을 줄인다.
3. 검색 유입을 신뢰 가능한 광고·제휴 수익으로 연결한다.

## 2. 독자와 핵심 사용 흐름

주요 독자는 휴대전화로 다음 행동을 완료하려는 국내 검색 사용자다.

```text
검색
→ 핵심 조건과 일정 확인
→ 준비물·비용·주의사항 확인
→ 공식 또는 제휴 목적지로 이동
→ 신청·발급·조회·예약·구매 완료
→ 문제 발생 시 후속 글에서 해결
```

내부 링크와 시리즈는 카테고리 유사성이 아니라 이 흐름이 실제로 이어지는지를 기준으로 구성한다.

## 3. 콘텐츠 범위

### 핵심 장기 콘텐츠

- 정부지원·복지·고용·장학 제도의 대상, 신청, 지급, 이의신청
- 주민·가족·소득·세금·보험·부동산·자동차 관련 증명서 발급
- 세금 신고·납부·환급과 생활 금융 실무
- 신청·예약·조회·다운로드 및 오류 해결
- 지역별 요금·신청처·운영시간처럼 고유값이 있는 생활정보
- 계산기와 조건 비교처럼 반복 방문 가치가 있는 도구형 정보

### 시의성 콘텐츠

- 현재 신청·판매·예매가 가능한 공연, 행사, 교통, 축제
- 공식 일정이 확인된 정책 변경과 마감 임박 공고
- 계절·명절·세금 일정처럼 발행 시점이 중요한 실용 정보

### 초기 확장을 피할 범위

- 공식 근거 없는 투자 예측과 건강 단정
- 지역명이나 연도만 바꾼 대량 문서
- 이미 종료되어 다음 행동이 없는 공연·이벤트
- 출처 불명 프로그램과 불법·우회 다운로드
- 광고 노출만을 목적으로 한 얕은 랜딩페이지

세부 작성 기준은 `docs/SSANGBAK_CONTENT_STANDARD.md`를 따른다.

## 4. 수익화 원칙

- 애드센스는 콘텐츠를 보조해야 하며 콘텐츠보다 광고가 앞서지 않는다.
- 유료 검색광고는 광고 수익만을 위한 차익거래보다 예약·구매·제휴 전환이 측정되는 구조를 우선한다.
- 제휴 콘텐츠는 공정위 고지와 링크 목적을 명확히 표시한다.
- 별도 도메인이나 서브도메인은 제재 회피가 아니라 독립된 서비스 가치가 있을 때만 사용한다.
- 유료 광고비는 사용자 승인 후 집행한다.

## 5. 기술 구조

- 프레임워크: Astro 5 정적 사이트
- 소스 콘텐츠: `src/content/posts/*.md`
- 사이트 주소: `https://ssangbak.com`
- 출력 디렉터리: `dist/`
- 호스팅 목표: Cloudflare Pages
- 소스 저장소: GitHub `kzz758258/ssangbak-static`
- 사이트맵: Astro sitemap 통합이 생성하는 `/sitemap-index.xml`
- 분석: GA4 설치
- 광고: Google AdSense 설치
- 배포: `main` 브랜치 푸시 후 Cloudflare Pages 배포
- 주제 탐색: GitHub Actions의 일일 topic radar

## 6. 품질 완료 조건

콘텐츠 또는 기능은 다음 조건을 만족해야 완료로 본다.

- 공식 근거와 기준일을 확인했다.
- 기존 글과 검색 의도가 중복되지 않는다.
- 제목, 본문, CTA, 목적지의 약속이 일치한다.
- 모바일과 PC에서 핵심 레이아웃이 깨지지 않는다.
- 관련 품질 검사와 빌드가 통과한다.
- 필요한 경우 실제 공개 URL, 이미지, 사이트맵을 확인했다.
- 운영 상태가 달라졌다면 `CURRENT_STATUS.md`를 갱신했다.
