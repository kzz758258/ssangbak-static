# SsangBak 유료광고 파일럿 계획

최종 확인: 2026-09-19

## 1. 결론

첫 Google Ads 파일럿은 **현재 판매 중인 상품을 비교·선택하게 돕는 네이버 쇼핑커넥트형 랜딩페이지**로 준비한다. 기존 폴드8 글 2개는 제휴 구조를 검증하는 참고 자산이지만 사전예약이 끝났으므로 그대로 광고하지 않는다.

광고 캠페인은 아직 만들거나 활성화하지 않는다. 랜딩페이지, 측정, 손익 기준을 먼저 완성하고 실제 예산은 사용자 승인 후 입력한다.

## 2. 수익모델 후보 비교

| 후보 | 직접 수익 전환 | 기존 준비도 | 정책 위험 | 운영 난도 | 판단 |
| --- | --- | --- | --- | --- | --- |
| 현재 판매 상품 비교 + 쇼핑커넥트 | 구매 수수료 | 폴드8 제휴 글·공통 고지 기능 보유 | 낮음~중간 | 중간 | 1차 파일럿 |
| 지역 여행·숙박 예약 제휴 | 예약 수수료 | 현재 저장소 밖의 사이트·제휴 상태 확인 필요 | 낮음~중간 | 높음 | 2차 후보 |
| 프로그램 다운로드·정부 신청·조회 정보 | 주로 애드센스 | 관련 정보 글 다수 보유 | 중간~높음 | 중간 | 유기 검색 우선 |

### 쇼핑커넥트형을 먼저 선택하는 이유

- 광고비와 연결할 수 있는 구매 수수료가 있어 순수 애드센스보다 손익 계산이 명확하다.
- 사이트에 `affiliateDisclosure`와 `rel="sponsored"` 구조가 이미 있다.
- 사용자가 과거에 실제 쇼핑커넥트 링크를 제공해 운영 경험이 있다.
- 별도 도메인을 바로 구매하지 않고 SsangBak에서 한 개의 파일럿을 검증할 수 있다.

### 프로그램 다운로드·신청·조회형의 위치

이 키워드는 계속 작성한다. 다만 공식 페이지로 이동하는 정보형 글은 자체 구매·예약 수수료가 없어 첫 유료광고의 경제성을 입증하기 어렵다. 다음 조건 중 하나가 생길 때 광고 후보로 다시 평가한다.

- 합법적인 소프트웨어·교육·업무도구 제휴 수익이 연결된다.
- 자체 계산기나 비교 도구가 반복 방문과 별도 수익을 만든다.
- 확정 수익 데이터를 통해 광고비보다 높은 방문당 가치가 검증된다.

## 3. 첫 랜딩페이지 선정 조건

아래 조건을 모두 만족하는 상품만 광고 후보로 삼는다.

1. 현재 구매 가능하고 재고·가격을 확인할 수 있다.
2. 제휴 링크와 수수료 대상 여부가 유효하다.
3. 한시적 사전예약이 끝나도 검색 의도가 일정 기간 유지된다.
4. 독자가 비교할 모델·용량·가격·유지비·반품 조건이 있다.
5. 공식 제조사 정보와 판매 페이지 정보가 서로 일치한다.
6. 광고 제목, 랜딩 제목, 버튼 목적지가 같은 상품을 약속한다.
7. 모바일에서 버튼과 광고가 혼동되지 않는다.

현재 폴드8 사전예약 글은 1번과 3번을 충족하지 않으므로 광고 대상에서 제외한다. 일반 판매 기준으로 전면 갱신하고 제휴 링크도 유효성을 재확인한 경우에만 다시 검토한다.

## 4. 권장 랜딩 구조

```text
제휴 고지
→ 누구에게 맞는 상품인지 한 문장 답변
→ 가격·모델·용량 비교표
→ 자급제와 통신사 구매 비용 차이
→ 상황별 추천과 선택하지 말아야 할 경우
→ 재고·배송·반품 확인사항
→ 제휴 상품 확인 버튼
→ 대안 모델과 FAQ
```

유료 방문자에게 애드센스 광고를 반복 노출하기 위한 중간 이동 페이지를 만들지 않는다. 파일럿 랜딩의 애드센스 비활성화 여부는 실제 페이지를 만들 때 별도로 결정한다.

## 5. 측정 설계

### 현재 추가된 GA4 이벤트

| 이벤트 | 조건 | 용도 |
| --- | --- | --- |
| `affiliate_outbound_click` | `rel="sponsored"` 링크 클릭 | 제휴 목적지 이동 측정 |
| `cta_click` | 제휴가 아닌 `.cta-button` 클릭 | 공식 신청·조회 등 일반 CTA 진단 |

개인정보나 URL 쿼리 문자열은 이벤트에 전송하지 않는다. 목적지 도메인·경로, 버튼 문구, 현재 페이지 경로만 기록한다.

### Google Ads에서 사용할 전환

- **주 전환:** 확정 구매 또는 확정 예약. 제휴 플랫폼이 전환 연동·캠페인 식별자를 제공할 때만 사용한다.
- **보조 전환:** `affiliate_outbound_click`. 사용자가 상품 페이지로 이동했다는 뜻일 뿐 구매로 간주하지 않는다.
- **진단 이벤트:** `cta_click`. 광고 입찰 최적화 대상으로 사용하지 않는다.

쇼핑커넥트가 구매 후 전환 콜백이나 캠페인 식별자를 제공하지 않으면 플랫폼 정산 자료와 GA4 클릭을 날짜·랜딩별로 수동 대조한다. 이 경우 Google Ads가 구매 전환을 학습한다고 표현하지 않는다.

## 6. 손익 계산

```text
확정 매출 = 취소·반품 차감 후 확정 제휴 수수료 + 확정된 보조 광고 수익
공헌이익 = 확정 매출 - Google Ads 비용 - 결제·도구 등 직접 비용
방문당 가치 = 확정 매출 ÷ 유료 랜딩 세션
손익분기 최대 CPC = 방문당 가치
```

예상 수수료나 애드센스 예상 수익이 아니라 **확정 수익**으로 판단한다. 광고 한도는 손익분기 최대 CPC보다 충분히 낮게 설정한다.

## 7. 캠페인 시작·중단 기준

### 시작 전 필수 조건

- [ ] 판매 중인 상품과 유효한 제휴 링크 확정
- [ ] 랜딩페이지 모바일·PC 검수
- [ ] 제휴 고지와 버튼 목적지 검수
- [ ] GA4 실시간 보고서에서 클릭 이벤트 수신 확인
- [ ] Google Ads와 GA4 연결
- [ ] 일일 예산과 최대 학습 손실을 사용자 승인으로 확정
- [ ] 검색 캠페인, 구문·일치 키워드, 제외 키워드 구성

### 즉시 중단 조건

- 상품 종료·품절·가격 또는 혜택의 중대한 불일치
- 광고 문구와 랜딩 또는 버튼 목적지 불일치
- 정책 경고, 광고 게재 제한, 비정상 클릭 급증
- 추적 누락으로 유료 세션과 행동을 구분할 수 없음
- 사전에 승인한 최대 학습 손실 도달

예산 증액은 확정 수익 기준 공헌이익이 양수이고, 취소·반품을 반영한 뒤에도 같은 결과가 유지될 때만 검토한다.

## 8. Google Ads 초기 설정 원칙

- 검색 캠페인만 시작한다.
- 자동 태그 추가를 사용한다.
- 초기에는 구문검색과 일치검색을 중심으로 구성한다.
- 디스플레이 네트워크와 AI Max는 켜지 않는다.
- 구매 전환 데이터가 없을 때 목표 CPA를 임의의 클릭 단가처럼 사용하지 않는다.
- 광고 효력과 최적화 점수는 참고 지표이며 수익 보장 지표로 보지 않는다.
- 일일 예산은 특정 날짜에 평균 일일 예산보다 더 사용될 수 있음을 감안해 월 한도를 계산한다.

## 9. 다음 입력값

다음 단계에서 사용자에게 필요한 것은 아래 세 가지다.

1. 현재 사용할 수 있는 쇼핑커넥트 상품 링크 또는 상품군
2. 상품별 예상 수수료를 확인할 수 있는 화면 또는 값
3. 파일럿에서 허용할 최대 총손실과 일일 예산

이 세 값이 준비되면 후보 상품의 검색 의도·경쟁·랜딩 구조를 조사하고 첫 광고용 페이지를 제작한다.
